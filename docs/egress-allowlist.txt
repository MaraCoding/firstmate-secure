# docs/egress-allowlist.txt - every network destination firstmate may name or reach.
#
# Format: <host> <class> <why>   (one per line; # comments; blank lines ignored)
# A host entry also covers its subdomains. Two tools read the first two columns:
#   tests/fm-egress-allowlist.test.sh  every hostname in the code and harness
#                                      directories must appear here (static)
#   bin/fm-egress-audit.sh             every remote connect() a traced run makes
#                                      must resolve to a host here (runtime)
# A merge from upstream that introduces a new host fails the static test until
# someone classifies it on a line below. That is the point: no endpoint lands
# unread. Classes:
#   forge         the git forge firstmate works against (gh, git over https)
#   provider      the model provider the primary and workers are logged into
#   guarded       opt-in third party; refused unconditionally under airgap
#                 (docs/airgap.md), reachable only with a credential AND no airgap
#   install-hint  printed as an install instruction; firstmate never fetches it
#   browser-asset fetched by the operator's browser when a generated page renders
#   doc           appears only in comments, docs, DTD/namespace strings, or fixtures

# --- forge -------------------------------------------------------------------
github.com            forge        gh, git, release downloads, status checks
githubusercontent.com forge        raw.githubusercontent.com: printed install hint for no-mistakes
githubstatus.com      doc          matched inside a gh error message, never fetched

# --- provider (runtime audit only; not named in firstmate's own code) ----------

claude.ai             provider     Claude harness login
